Strategi Promosi Wardah (halaman demo)

Cara membuka: klik dua kali index.html. Tidak perlu install apa pun dan tidak perlu internet
(tanpa internet hanya jenis huruf yang berganti ke huruf bawaan).

Isi:
- index.html : halaman lengkap. Data 8 kategori, bobot model sentimen (Logistic Regression),
  dan kode penebak sudah ada di dalam file ini.
- model.json : bobot model dan kamus pembersihan teks, sama dengan yang tertanam di index.html.
  Disertakan sebagai arsip, tidak dibutuhkan untuk membuka halaman.

Catatan: penebak sentimen di browser menirukan pembersihan teks di notebook (stopword, slang,
stemming). Diuji pada 300 ulasan: label dan probabilitas sama dengan model Python.
